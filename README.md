# VOLTIS — Electric Mobility Homepage Prototype

Prototype trang chủ cho VOLTIS, một concept thương hiệu/cửa hàng xe ô tô điện.

## Stack

- HTML thuần
- CSS thuần
- JavaScript thuần
- Không framework, không build step
- Sẵn sàng deploy GitHub Pages

## Chạy local

Có thể mở trực tiếp `index.html` hoặc dùng một static server bất kỳ. Prototype không phụ thuộc localhost/API.

## GitHub Pages

Trong repository: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.

## Lưu ý nội dung

- VOLTIS, AERO và TERRAIN trong prototype là nội dung concept.
- Hình xe là SVG nguyên bản phục vụ prototype.
- Không sử dụng logo, hình ảnh hoặc tài sản thương hiệu của các hãng xe tham khảo.
- Email `.example` là địa chỉ minh họa an toàn và cần được thay trước khi production.
