Prototype scope

Real interaction.
Clear concept boundaries.

The prototype is intentionally honest about what is coded, what is simulated and what is still a future-state specification.

Navigation

9 public routes

Responsive navigation connects product, company, project, editorial, resource, gallery, career and contact experiences.

Interactive behavior

HTML · CSS · JS

Mobile navigation, story filtering, resource search, homepage interactions and media refinement are implemented client-side.

Contact

Prototype only

The contact form demonstrates information architecture and states but is not connected to a production CRM or backend.

Vehicle data

Concept direction

AERO and TERRAIN communicate design intent without inventing production range, performance or certification figures.

Reference media

Tesla direction

The live site uses Tesla-hosted reference media with source labeling; the presentation screens use local concept assets where possible.

Accessibility

Keyboard + reduced motion

Focus visibility, semantic controls, 44–48px targets and reduced-motion behavior are part of the visual system.
