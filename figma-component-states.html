02 / States

Fast feedback. Low noise.

InputResponse

VOLTIS state changes are short and explicit. Green confirms energy, availability, focus and selected intent. Orange is reserved for change, warning and corrective attention.

Every state preserves layout so feedback never causes the interface to jump.

one behavior model.
