04 / User flows

Move with intent.

DiscoverAct

VOLTIS is not an e-commerce prototype, so the meaningful conversion is not Cart → Checkout. The core task is to move from interest to enough evidence to start the correct vehicle, project or partnership conversation.

Flows below are mapped directly to the current HTML routes and anchors.

Primary flow

Explore vehicle →
register interest.

The main product journey gives visitors a fast path from brand proposition to model intent and then into a routed contact experience.

Flow rules

Reduce uncertainty
before conversion.

The user should never be asked to contact VOLTIS before enough context exists to choose the right conversation.

01 / Entry

Multiple valid starts

Home, Vehicles, Stories and Resources can all be legitimate entry points from search, portfolio or direct links.

02 / Decision

Evidence before action

Model intent, project proof or document context should be visible before a high-commitment contact CTA.

03 / Goal

Route the enquiry

Vehicle, infrastructure and partnership intent should not collapse into one ambiguous generic message.
