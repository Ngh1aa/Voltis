# VOLTIS — Visual Signature

## Strongest source cues

There is no existing brand guideline. Current source-of-truth is the user-provided strategic direction: **VOLTIS + electric automotive + black/green/orange + modern/future/environmental**. Everything below is a working system for the prototype, not an official corporate identity.

## Digital signature cues

### 1. Energy Rail — primary signature
A thin linear path with nodes / gaps / state changes. It is used to:
- guide reading direction;
- represent energy/state;
- connect technical objects;
- create continuity across sections.

It should never become a glow-heavy decorative line.

### 2. Instrument Indexing — supporting signature
Short labels like `01 /`, `02 /`, `REV. 01`, tick marks, meters and compact metadata. The cue comes from automotive instrumentation but stays at L1/L2 metaphor fidelity.

### 3. Color behavior
- Energy Green = available / energy / primary next action.
- Motion Orange = change / kinetic moment / secondary peak.
- Carbon/Paper alternation = technical vs evidence/editorial mode.

### 4. Composition rhythm
Large object + spare copy; technical dense field alternates with editorial light field. Not every section uses the same card grammar.

### 5. CTA treatment
Rectangular, low-decoration controls. Primary green button is intentionally rare. Secondary buttons use border/neutral surface.

### 6. Motion language
Short, decisive transitions; one main activation moment; no perpetual decorative loops except a non-essential hero ticker that honors reduced motion.

## Generic category patterns to avoid

- black + neon green as a full-page glow aesthetic;
- full-bleed competitor-like vehicle photography;
- glassmorphism;
- icon bubble grids;
- giant centered statement on every section;
- fake technical KPI blocks;
- “eco leaf” visuals as sustainability proof.

## Recognition QA

Crop logo/header/footer and inspect:
1. Is an Energy Rail or technical indexing cue present?
2. Does color behavior remain consistent?
3. Does the screen feel automotive/energy-specific rather than SaaS?
4. Is at least one major object tied to a real page task?
5. Are controls still familiar and accessible?

If answer to 1–3 is consistently “no,” the page is visually drifting.
