## Selection rule

- Google and Pinterest are used only to discover composition references and search directions.
- The deployed page points to the original/primary image host or a source with an explicit reuse license whenever possible.
- No Pinterest repost URL, Google Images cache URL, watermark, or screenshot is embedded in the production HTML.
- All photo frames use `object-fit: cover`, responsive sizing, and descriptive alternative text.
