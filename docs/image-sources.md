# VOLTIS — Curated Image Sources

Updated: 10 September 2026

This prototype uses external photography only as visual-reference material for the VOLTIS UI/UX concept. AERO, TERRAIN and VOLTIS remain fictional concept content; vehicles and brands visible in reference photography belong to their respective owners.

## Selection rules

- Google Images and Pinterest are used only for discovery and composition research.
- Deployed imagery points to a primary source or to photography with an explicit reuse licence wherever possible.
- No Google cache URL, Pinterest repost, watermark or screenshot is embedded in the site.
- Photography is selected by content role: vehicle form, cabin/interface, charging, energy, engineering, documentation or collaboration.
- Every image uses descriptive `alt` text, responsive cropping and an error fallback where an earlier image is available.
