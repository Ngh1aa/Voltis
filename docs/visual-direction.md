# VOLTIS — Visual Direction

## Visual attributes

1. **Technical, not sterile** — grid/index/meter carry information, while warm paper and orange keep the system human.
2. **Futuristic, not neon-cliché** — future feel comes from composition, object scale and energy-flow grammar.
3. **Premium, not luxury-cosplay** — large type, restraint and strong alignment; no fake marble, chrome or excessive blur.
4. **Responsible, not “eco-themed”** — sustainability is represented through evidence structure instead of leaf motifs.
5. **Kinetic, not busy** — motion is concentrated in rail/state transitions, not decorative loops.

## Layout grammar

- **Container:** fluid shell, max ~1500px; side gutter 20px mobile → 48px desktop.
- **Desktop hero:** asymmetric 44/56-ish split; owner message left, vehicle decision object right.
- **Section rhythm:** alternate dark technical fields / light evidence fields; large vertical breath.
- **Alignment:** left-led editorial grid; centered text is exceptional.
- **Radius:** mostly square/low-radius surfaces. Circular geometry reserved for instrument/meter behavior.
- **Cards:** only when the content is truly a grouped object; avoid “cardify everything”.

## Hierarchy

`Display statement → H2 section decision → H3 object title → body explanation → technical meta/index`

- Hero display is short and line-broken intentionally.
- Micro labels use uppercase only for short technical/index content.
- Vietnamese body remains sentence case.

## Color role map

- `#090C0B` Carbon: primary dark field.
- `#101512` Graphite: technical object surface.
- `#F0F2EC` Warm Paper: evidence/editorial field.
- `#8DFF63` Energy Green: primary CTA + energy/state.
- `#FF7A1A` Motion Orange: motion/change/secondary peak.
- Muted greys separate support text without reducing contrast below usable levels.

## Type

- Prototype uses a resilient system font stack.
- Display: heavy-ish grotesk, aggressive letter spacing only at large sizes.
- Body: readable sans, 55–68ch.
- Avoid micro-copy below 10px; interactive labels ≥12px where practical.

## Media art direction

### Prototype
- Original vector concept cars only.
- Dark technical backgrounds with controlled grid.
- No competitor logos, cars, showroom photography or branded UI.

### Production future state
- Product photography should emphasize **clear silhouette + material + driving context**, not generic studio glamour.
- Use consistent crop safe zones.
- If lifestyle photography is introduced, subject and product must remain legible at mobile crops.

## Domain artifact synthesis

Primary source metaphor: **automotive instrument cluster + electrical energy path**.

- Instrument cluster → L1/L2 cues: indexing, meter, segmented state, arc.
- Energy flow → L2 structural cue: rail/path connecting decision points.
- Spec sheet / technical ledger → L2 structure for product evidence and sustainability data.

Do not recreate a literal dashboard, fake battery schematic or branded OEM cluster.

## Motion

- Micro state: 170ms.
- Normal UI transition: 260ms.
- Hero activation / reveal: ~640–900ms, non-blocking.
- One-time reveal only at major composition group level.
- Reduced-motion disables large translation/ticker loops.

## Three composition proofs

### Proof A — Home hero
```text
[Owner message / CTA / meta]   [large vehicle object]
[-------------------------------- energy ticker --------]
```

### Proof B — Responsibility
```text
[large statement / rationale]  [impact ledger / evidence rows]
```

### Proof C — Product detail future route
```text
[vehicle object full-width]
[sticky/model index] [real specifications + primary action]
```

These three prove the system is consistent without forcing a single hero shell.

## Visual taste calibration

- **Memorable commitment:** Energy Rail.
- **Generic tells found in category:** neon-green glow, centered hero, glass panels, repeated rounded cards.
- **KEEP:** large product object, restrained dark surface, technical numbers.
- **REVISE:** green is state/energy rather than mood; cards become object-specific compositions.
- **REMOVE:** random gradient orb, decorative icon badges, pervasive glass blur, fake metrics.
- **Representative verification:** home hero, energy system diagram, impact ledger use distinct compositions but share type/index/rail behavior.

## Do / Do not

**Do**
- make product and evidence the largest objects;
- use green/orange by role;
- let numbers/indexes structure content;
- preserve familiar navigation/button behavior;
- label concept/unknown status.

**Do not**
- clone category hero layouts;
- use every section as centered heading + 3 rounded cards;
- imply commercial product truth from concept artwork;
- add motion without a feedback/hierarchy/state job;
- let small technical labels replace descriptive text.
